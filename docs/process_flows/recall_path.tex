\chapter{Process Flow: The Recall Path (Bounded)}
This is the ``middle part'': what happens between the utterance and the context the agent receives.
Tottie answers it with the \textbf{Context Card} (ambient) plus the \textbf{probe} (deliberate), all
inside a hard time budget.

\section{A New Turn Arrives}
\textbf{Trigger:} The user sends \emph{``when is her birthday again?''}, or a fresh session opens.
\textbf{Action / UI State:} The sprite enters \texttt{thinking}; the Panel prepares a ``CONTEXT
INJECTED THIS TURN'' block.
\textbf{System Logic:} The host calls \texttt{POST /recall}. A wall-clock budget starts (300 ms p95).
\textbf{Data Flow \& Mutators:} The utterance (plus the last assistant turn) is embedded in a thread
pool.

\section{The Identity Slice Is Always Included}
\textbf{Trigger:} Any recall.
\textbf{System Logic:} \texttt{SELECT ... WHERE tier='identity' AND valid\_to IS NULL AND NOT
quarantined}. Unconditional and cheap --- identity has zero search overhead.
\textbf{Data Flow \& Mutators:} Identity facts collected for the card header.

\section{Three Legs in One Round-Trip}
\textbf{Trigger:} The utterance embedding plus the owner scope.
\textbf{System Logic:} A single SQL statement runs:
\begin{enumerate}
  \item \textbf{Vector} leg: HNSW top-50 by cosine;
  \item \textbf{Lexical} leg: full-text top-50 (bound parameters only);
  \item \textbf{Filter}: \texttt{owner = ?} AND \texttt{valid\_to IS NULL} AND \texttt{NOT quarantined};
  \item \textbf{Fusion}: Reciprocal Rank Fusion, $k=60$, to top-8.
\end{enumerate}
The session sets \texttt{hnsw.ef\_search = 100} and \texttt{hnsw.iterative\_scan = strict\_order}
(pgvector $\geq$ 0.8). Candidates are still \textbf{over-fetched} (50 per leg) before filtering,
as belt-and-braces for older servers.
\textbf{Data Flow \& Mutators:} A ranked hit list of \texttt{(id, tier, summary, tags, score, trust)}.

\section{Spreading Activation and Completion}
\textbf{Trigger:} The ranked seed set.
\textbf{System Logic:} The \textbf{Activator} walks \texttt{memory\_links} in Python BFS: at most
\textbf{2 hops}, at most \textbf{50 nodes}, decay 0.5, with a cycle guard. The \textbf{Completer}
reconstructs the top cluster. Both honour the wall-clock budget; if it is exhausted, the pipeline
returns what it has rather than failing.
\textbf{Data Flow \& Mutators:} An activation-merged candidate set.

\section{Confidence (Metacognition)}
\textbf{Trigger:} The final candidate set.
\textbf{Action / UI State:} The Panel shows a confidence chip (know / verify / abstain).
\textbf{System Logic:} \texttt{confidence = 0.4 * margin + 0.4 * coverage + 0.2 * top1cos},
where \texttt{margin = clamp((top1 - top2) / top1, 0, 1)} is the RRF distinctiveness,
\texttt{coverage} is the fraction of query content words (stopwords stripped) found in the
hits' tags+content, and \texttt{top1cos} is the exact top-1 vector cosine. Recalibrated R2:
ranks alone scored a known single-leg fact (0.311) identically to best-of-bad-lot noise
(0.311), abstaining on knowledge; the three-signal blend separates them (0.518 vs 0.244 on the
same store). Below \textbf{0.35} the result is flagged ``verify or abstain''. This is the
difference between hallucinating and saying ``I don't have that''. Two abstain semantics,
locked W2: the identity header still rides the card (pinned user truths, not retrieved
guesses), and \texttt{hits} stay populated for Panel transparency while \texttt{card} carries
no ranked lines --- the host injects nothing. Known limit: negation is invisible to coverage
(``not a vegetarian'' covers like ``vegetarian'') --- out of scope for the hackathon.
\textbf{Data Flow \& Mutators:} A confidence value attached to the recall event.

\section{Curate and Inject}
\textbf{Trigger:} The completed cluster and its confidence.
\textbf{Action / UI State:} The Panel shows the exact card, each line annotated with \emph{why} it
surfaced (cue type $\rightarrow$ seed $\rightarrow$ hops) and its \emph{source}.
\textbf{System Logic:} The \textbf{Curator} assembles the card within a \textbf{400-token} budget,
fencing memory content as \emph{data} (never instructions) and appending the ``probe deeper'' pointers.
\textbf{Data Flow \& Mutators:} The card is injected into the prompt; a \texttt{recall} event is
streamed to the Panel.

\section{Prospective Check (no scheduler)}
\textbf{Trigger:} Every recall (write-side checks deferred to W4: the 202 write path has
no response channel for fired banners until the Panel/MCP surface exists).
\textbf{System Logic:} There is no background scheduler. Instead, each recall checks the
Prospective Queue inline: any \texttt{pending} intention whose \texttt{time\_cue} has passed
fires now (status $\rightarrow$ \texttt{fired}), and any whose \texttt{event\_cue} overlaps the
turn's entities fires now. Fired intentions ride along in the recall response
(\texttt{fired\_intentions}) and the Panel renders them as a ``remember to\ldots'' banner.
\textbf{Data Flow \& Mutators:} A read of \texttt{(owner, status, time\_cue)} plus a status flip
on fire. A time-cue can only fire late by (at most) the gap between turns --- acceptable for a
demo, documented for honesty.

\section{The Retrieval Story (3-stage chain)}
\textbf{Trigger:} Any recall whose hits are shown to the user.
\textbf{Action / UI State:} The Panel narrates the story line while the brain graph lights the
path: \emph{``food $\rightarrow$ 1,420 candidates $\rightarrow$ narrowed by T-3d + restaurant
context $\rightarrow$ Bistro Visit (+0.34 over Home Lunch) $\rightarrow$ then: seated, ordered,
paid.''}
\textbf{System Logic:} The backend reports the chain in three stages, transferred from the
notebook research (cue overload, compound context probe, distinctiveness selection + contiguity
unroll): (1) the raw cue plus candidates-matched (overload); (2) the context features that joined
the probe (time, session, entities); (3) the winner plus its \textbf{distinctiveness margin} over
the runner-up (the confidence numerator, already computed) plus temporal neighbours unrolled by
contiguity. The ordered node ids ride in the response as \texttt{path:[ids]}.
\textbf{Data Flow \& Mutators:} Read-only; the story is rendered from the recall event, which
already carries cue, hits, scores, and confidence.

\section{The Deliberate Probe}
\textbf{Trigger:} The agent decides it needs more depth than the card provides.
\textbf{System Logic:} \texttt{memory.probe(tag)} returns the room's live, non-quarantined memories,
subject to the same budget.
