\chapter{Process Flow: The Write Path (Non-Blocking)}
Every step below is what the \textbf{Memory Panel} renders in its ``LEARNING NOW'' block. The write
never blocks the user's turn: the request is acknowledged, then curated in the background.

\section{The Host Posts a Turn}
\textbf{Trigger:} The user says something durable --- e.g.\ \emph{``my girlfriend's birthday is on the
7th of November''}.
\textbf{Action / UI State:} The sprite enters \texttt{listening} then \texttt{thinking}; the Panel
prepends a turn card with an empty ``LEARNING NOW'' row.
\textbf{System Logic:} The host issues \texttt{POST /write} with
\texttt{\{text, session\_id, turn, owner, source\}}. The route validates the token, computes an
\textbf{idempotency key} from \texttt{(session, turn, content)}, enqueues the turn on a bounded queue,
and returns \texttt{202 \{event\_id\}} in under 20 ms.
\textbf{Data Flow \& Mutators:} A queued item plus a \texttt{memory\_event} stub; nothing is written to
\texttt{memories} yet.

\section{A Worker Drains the Queue}
\textbf{Trigger:} A free write worker.
\textbf{Action / UI State:} The Panel's row begins to fill.
\textbf{System Logic:} The worker runs the gate chain in order:
\begin{enumerate}
  \item \textbf{heuristic pre-filter} --- skip obvious chit-chat without calling a model;
  \item \textbf{Attention Gate} --- discard noise (heartbeats, acknowledgements);
  \item \textbf{Surprise Gate} --- compute the prediction error; discard the routine;
  \item \textbf{Observer} --- score salience and propose candidates.
\end{enumerate}
\textbf{Data Flow \& Mutators:} \texttt{observer\_verdict} recorded; a suppressed turn ends here with a
dimmed chip and no \texttt{memories} row.

\section{Trust and Quarantine}
\textbf{Trigger:} A candidate whose \texttt{source.trust} is \texttt{tool} or \texttt{web} and whose
kind is an identity fact or a convention.
\textbf{Action / UI State:} The Panel shows the memory under a \textbf{PENDING} strip rather than in the
active list.
\textbf{System Logic:} The row is written with \texttt{quarantined = true}; it is \textbf{never}
injected into the Context Card until the user confirms. This is the control that stops memory poisoning.
\textbf{Data Flow \& Mutators:} \texttt{INSERT} with \texttt{trust} and \texttt{quarantined} set.

\section{Structure, Embed, Reconcile}
\textbf{Trigger:} A non-empty, trusted candidate list.
\textbf{Action / UI State:} The Panel shows the operation badge (\texttt{NEW} / \texttt{UPDATE} /
\texttt{SUPERSEDE} / \texttt{SKIP}), the tier chip, and the room chips.
\textbf{System Logic:} The Scribe composes the memory, embeds it (thread-pooled, $\leq$ 512 tokens),
and reconciles against the live rows for \texttt{(owner, subject, predicate)} under the partial unique
index; the routed tier is recorded.
\textbf{Data Flow \& Mutators:} \texttt{INSERT/UPDATE memories}; links written on tag/entity/supersede
events; a \texttt{memory\_event} emitted with a monotonic id.

\section{Failure Fallback}
\textbf{Trigger:} The Observer or Scribe call fails, times out, or returns invalid JSON.
\textbf{Action / UI State:} The Panel shows a ``raw --- will curate later'' chip.
\textbf{System Logic:} The turn is written as a \textbf{raw episodic row} with
\texttt{needs\_curation = true}; the Consolidator curates it on the next Sleep. A model outage must
never lose a turn.
\textbf{Data Flow \& Mutators:} \texttt{INSERT} with \texttt{needs\_curation}; a retry counter on the
event.

\section{Streaming Back}
\textbf{Trigger:} Any of the above completes.
\textbf{System Logic:} The event is pushed over \texttt{GET /events} (SSE) with a monotonic id, so a
reconnecting Panel can resume from \texttt{Last-Event-ID} and never miss a step.
