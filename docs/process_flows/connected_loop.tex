\chapter{The Connected Loop}
\label{ch:connected-loop}

There are two honest ways to test Tottie, and one dishonest way that is
banned. The dishonest way is telling the agent to remember: any turn
containing a curation instruction (``remember this'', ``store that'') is
manual curation theater, and any finding that depends on such turns is
void. Both honest modes below forward raw working turns and let the
Observer alone decide keep versus drop.

\section{Mode 1: Drill (subagent as developer, manager as human)}

One subagent plays the developer role and the manager plays the human:
terse instructions, nothing restated, past work referenced the way a
real user references it. Each turn the harness pastes the
\verb|memory.brief| block and the human instruction; the subagent builds
real artifacts on disk. Memory accumulates underneath the work. The
probe is never scripted: at a natural point the human gives an
instruction that assumes earlier context, and the run passes or fails on
whether the brain supplied it. Drill runs 1--2 (roommate expense
splitter) found G1 (familiarity eating reversals), G1c (active route
shadowing the verified target), and G3 (entailment swallowing
extensions) --- all invisible to the green pytest suite.

\section{Mode 2: Connected (the agent works, the brain watches)}

The working agent connects over MCP stdio (\verb|core/server.py|) and
follows the host contract every turn: \verb|memory.brief| first (paste
the block into context), raw thinking and output forwarded through
\verb|memory.remember| (full Observer pipeline, Scribe decides),
\verb|memory.recall| and \verb|memory.probe| when depth is needed.
Nothing is ever marked ``to remember''. The Observatory UI watches the
same owner live: the Timeline streams every event over SSE and the 3D
brain re-grows on each write, so memories are seen forming as the agent
learns. Proven 2026-10-31: a connected research run kept 5/5 content
turns and dropped 2/2 noise turns with zero curation instructions, and
the owner graph grew to 18 nodes / 55 links during the session.

\section{Honesty rules (both modes)}

\begin{enumerate}
\item Never instruct remembering. Turns carry work, never curation verbs.
\item Verify independently: rerun the artifact, query the store, read the event ledger. Agent reports are claims, not evidence.
\item Failures are findings. A dropped reversal or an eaten extension is logged with its verdict signature, never reworded away.
\item Name the boundary. Thresholds, NLI labels, and LLM scribe output are fuzzy; only the reconcile algebra around them is exact.
\end{enumerate}
