\chapter{Data Model and Storage}

\section{Storage Decision (documented exception)}
Local development across the NKNGO ecosystem uses SQLite. Tottie is an explicit, reasoned
exception: \textbf{semantic memory requires vector search}, and the ecosystem's canonical RAG
engine (\texttt{ask.nkngo}) and Pattern already run \textbf{Postgres + pgvector} locally. Tottie
therefore uses a local \texttt{tottie} database on \texttt{127.0.0.1:5432}. This is a deliberate
deviation, recorded here per the workspace's non-destructive documentation standard.

\section{Schema}
\begin{Verbatim}[breaklines=true,fontsize=\small]
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE memories (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  owner       text NOT NULL,                 -- user / tenant scope
  tier        text NOT NULL CHECK (tier IN ('identity','episodic','knowledge','procedural')),
  kind        text NOT NULL,                 -- fact | preference | decision | event | doc | lesson
  subject     text,                          -- e.g. 'girlfriend', 'server_c', 'tottie'
  predicate   text,                          -- e.g. 'birthday', 'uses_db', 'fix'
  object      text,                          -- e.g. '2026-11-07', 'pgvector'
  content     text NOT NULL,                 -- human-readable memory
  summary     text,                          -- short form for the Context Card
  embedding   vector(384),                   -- bge-small-en-v1.5
  tags        text[] NOT NULL DEFAULT '{}',  -- the "rooms": #person/frans, #project/tottie
  salience    real NOT NULL DEFAULT 0.5,     -- write-time importance 0..1
  confidence  real NOT NULL DEFAULT 1.0,
  source      jsonb,                         -- {session_id, turn, doc, url, msg_id}
  supersedes  uuid REFERENCES memories(id),  -- temporal chain
  valid_from  timestamptz NOT NULL DEFAULT now(),
  valid_to    timestamptz,                   -- NULL = currently true
  hash        text,                          -- dedupe / content hash
  created_at  timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE memory_events (                 -- the X-ray feed + the eval ledger
  id               uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  ts               timestamptz NOT NULL DEFAULT now(),
  session_id       text,
  turn             int,
  utterance        text,
  observer_verdict jsonb,                    -- {keep, salience, reason, candidates}
  scribe_action    jsonb,                    -- {op, tier, kind, tags, memory_id}
  latency_ms       int,
  tokens           int
);
\end{Verbatim}

\section{Indexes}
\begin{Verbatim}[breaklines=true,fontsize=\small]
CREATE INDEX ON memories USING hnsw (embedding vector_cosine_ops);   -- vector recall
CREATE INDEX ON memories USING gin (tags);                            -- room/tag filter
CREATE INDEX ON memories USING gin (to_tsvector('english', content)); -- full-text (lexical)
CREATE INDEX ON memories (owner, tier) WHERE valid_to IS NULL;        -- live-slice lookup
\end{Verbatim}

\section{Temporal Correctness}
Every fact carries a validity window. When a new fact contradicts an old one, the Scribe sets the
old row's \texttt{valid\_to = now()} and inserts the new row with \texttt{supersedes = old.id}.
Retrieval filters \texttt{valid\_to IS NULL}, so \textbf{stale facts are never returned} and the
agent never has to reconcile in-prompt. This mirrors the temporal-graph behaviour of Zep/Graphiti.

\section{Owner Scoping}
All reads and writes are scoped by \texttt{owner}. The demo runs a single owner
(\texttt{owner\_local}), but the schema is multi-tenant from day one: identity, recall, probe, and
forget all take an owner key, so the same engine can serve many users without cross-contamination.

\section{Embeddings}
Real embeddings use FastEmbed \texttt{BAAI/bge-small-en-v1.5} (384-d), loaded from the local model
cache (\texttt{../../local LLMS}). A clearly-labelled \texttt{TOTTIE\_EMBEDDER=hash} dev fallback
exists \emph{only} for offline smoke tests and is never presented as production behaviour.
