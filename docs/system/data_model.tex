\chapter{Data Model and Storage}

\section{Storage Decision (documented exception)}
Local development across the NKNGO ecosystem uses SQLite. Tottie is an explicit, reasoned
exception: \textbf{semantic memory requires vector search}, and the ecosystem's canonical RAG engine
(\texttt{ask.nkngo}) and Pattern already run \textbf{Postgres + pgvector} locally. Tottie therefore
uses a local \texttt{tottie} database on \texttt{127.0.0.1:5432}, accessed through an
\textbf{async psycopg pool} (\texttt{AsyncConnectionPool}, not a connection per request).
The server needs \textbf{pgvector $\geq$ 0.8} for iterative filtered scans (see \emph{Indexes}).

\section{Schema}
\begin{Verbatim}[breaklines=true,fontsize=\small]
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE memories (
  id uuid PRIMARY KEY, owner text NOT NULL,
  tier text NOT NULL CHECK (tier IN ('identity','episodic','knowledge','procedural')),
  kind text NOT NULL, subject text, predicate text, object text,
  content text NOT NULL, summary text,
  embedding vector(384), embedding_model text,      -- model identity: a swap is detected
  tags text[] NOT NULL DEFAULT '{}',
  salience real DEFAULT 0.5, surprise real DEFAULT 0.0, arousal real DEFAULT 0.0,
  confidence real DEFAULT 1.0,
  utility real DEFAULT 1.0,                          -- RANKING signal, never a delete signal
  trust text NOT NULL DEFAULT 'user_direct',         -- user_direct | tool | web | model_inferred
  quarantined boolean NOT NULL DEFAULT false,        -- low-trust: visible, NOT injected
  needs_curation boolean NOT NULL DEFAULT false,     -- raw fallback awaiting the Scribe
  principle text, access_count int DEFAULT 0, last_access timestamptz,
  source jsonb, supersedes uuid REFERENCES memories(id),
  valid_from timestamptz DEFAULT now(), valid_to timestamptz,
  hash text, created_at timestamptz DEFAULT now()
);

CREATE TABLE memory_events (            -- monotonic log: SSE cursor + eval ledger
  id bigserial PRIMARY KEY, ts timestamptz DEFAULT now(),
  session_id text, turn int, utterance text,
  observer_verdict jsonb, scribe_action jsonb, cue jsonb, latency_ms int, tokens int
);

CREATE TABLE memory_links (             -- the associative index ("hippocampus")
  id uuid PRIMARY KEY, owner text NOT NULL,
  src uuid REFERENCES memories(id) ON DELETE CASCADE,
  dst uuid REFERENCES memories(id) ON DELETE CASCADE,
  relation text NOT NULL, weight real DEFAULT 1.0,
  UNIQUE (owner, src, dst, relation)
);

CREATE TABLE intentions (               -- prospective memory ("remind me to...")
  id uuid PRIMARY KEY, owner text NOT NULL, content text NOT NULL,
  event_cue text, time_cue timestamptz,
  status text NOT NULL DEFAULT 'pending', created_at timestamptz, fired_at timestamptz
);

CREATE TABLE schema_migrations (      -- ledger: baseline + applied migrations
  name text PRIMARY KEY, applied_at timestamptz DEFAULT now()
);
\end{Verbatim}

\section{Indexes (and why each exists)}
\begin{Verbatim}[breaklines=true,fontsize=\small]
CREATE INDEX ON memories USING hnsw (embedding vector_cosine_ops)
  WITH (m = 16, ef_construction = 64);                                -- vector leg
CREATE INDEX ON memories USING gin (tags);                           -- room/tag filter
CREATE INDEX ON memories USING gin (to_tsvector('english', content));-- lexical leg
CREATE INDEX ON memories (owner, tier) WHERE valid_to IS NULL;       -- live slice
CREATE INDEX ON memories (owner, utility);                           -- ranking / decay
CREATE INDEX ON memories (owner) WHERE quarantined;                  -- pending strip
CREATE INDEX ON memories (owner) WHERE needs_curation;               -- curation backlog
CREATE INDEX ON memory_links (owner, src);
CREATE INDEX ON memory_links (owner, dst);
CREATE INDEX ON intentions (owner, status, time_cue);
CREATE UNIQUE INDEX ON memories (owner, subject, predicate, quarantined)
  WHERE valid_to IS NULL AND subject IS NOT NULL;   -- serialise reconcile, per partition
CREATE UNIQUE INDEX ON memories (owner, hash)
  WHERE hash IS NOT NULL;                           -- idempotent writes
CREATE UNIQUE INDEX ON memory_events (session_id, turn, utterance)
  WHERE turn IS NOT NULL;                           -- exactly-once turns
\end{Verbatim}
Post-baseline changes ship as migrations (\texttt{core/migrations/}, ledgered): 001 scoped the
live-SP index per quarantine partition so a quarantined row coexists with the clean row it
shadows; 002 made turns exactly-once under concurrent retries.
Filtered vector search is the known pgvector trap: the index returns its candidates by pure
distance and the \texttt{WHERE} clause is applied \emph{afterwards}, so a selective filter can
starve the result below $k$. Two defences, in order: (1) the session sets
\texttt{hnsw.ef\_search = 100} and \texttt{hnsw.iterative\_scan = strict\_order}, which makes
pgvector ($\geq$ 0.8) keep walking the graph until enough rows pass the filter; (2) retrieval
still \textbf{over-fetches} the top 50 per leg before filtering by owner, validity, and trust,
as belt-and-braces for older servers. The harness asserts recall@k on a filtered fixture so a
regression here fails loudly instead of silently returning short lists. Partial-index trap,
verified W1: the idempotency index carries \texttt{WHERE hash IS NOT NULL}, and Postgres only
matches \texttt{ON CONFLICT (owner, hash)} against it when the statement repeats the predicate
--- without it every write dies with ``no unique or exclusion constraint matching the ON
CONFLICT specification''. The Scribe's insert therefore spells out the full
\texttt{ON CONFLICT (owner, hash) WHERE hash IS NOT NULL DO NOTHING}.

\section{The Field Semantics That Matter}
\begin{itemize}
  \item \texttt{utility} is a \textbf{ranking} signal (affects search weight and card inclusion). It is
  \emph{not} a delete signal --- see \emph{The Cognition Model}.
  \item \texttt{surprise} is the prediction error recorded at write time; it multiplies salience.
  \item \texttt{trust} / \texttt{quarantined} are the security controls (see \emph{Security}).
  \item \texttt{needs\_curation} marks the raw fallback written when a model call fails.
  \item \texttt{embedding\_model} lets the store refuse to compare vectors from different models.
\end{itemize}

\section{Temporal Correctness}
Every fact carries a validity window. When a new fact contradicts an old one --- and especially when
the old one was \emph{just retrieved} --- the old row's \texttt{valid\_to} is set to \texttt{now()} and
the new row is inserted with \texttt{supersedes = old.id}. Retrieval filters
\texttt{valid\_to IS NULL}. The partial unique index on \texttt{(owner, subject, predicate)} for live
rows serialises concurrent contradictions so two writers cannot both believe they are current.

\section{Owner Scoping}
All reads and writes are scoped by \texttt{owner}. The demo runs a single owner
(\texttt{owner\_local}), but every operation takes an owner key, so the schema is multi-tenant from
day one.

\section{Embeddings}
FastEmbed \texttt{BAAI/bge-small-en-v1.5} (384-d), loaded once from the local cache
(\texttt{EMBEDDING\_CACHE\_DIR}, default \texttt{../../local LLMS}). The loader \textbf{fails loudly}
if the model is missing (never a silent \texttt{None}), and every call runs in a thread pool so the
synchronous ONNX call cannot block the event loop. Input is capped at the model's \textbf{512-token}
limit --- longer content is summarised or chunked, never silently truncated.
