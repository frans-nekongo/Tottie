\chapter{System Architecture}

\section{Overview}
Tottie is a memory layer that any agent can mount. The \textbf{core engine} owns the memory
lifecycle; the \textbf{MCP server} is the transport that exposes it; the \textbf{Tottie UI} and any
\textbf{IDE coding agent} are consumers that share the same store. The engine's behaviour is specified
in the preceding part, \emph{The Cognition Model}.

\section{The Tier Model}
\begin{itemize}
  \item \textbf{Identity} --- persona and permanent constraints. Pinned \emph{raw} into the card,
  zero search overhead. (Example: a partner's birthday.)
  \item \textbf{Episodic} --- chronological decisions, state changes, and history.
  \item \textbf{Knowledge} --- ingested documents, files, and references (semantic facts).
  \item \textbf{Procedural (``Lessons'')} --- mistake $\rightarrow$ problem+solution pairs, surfaced
  instantly on recurrence (``autosave'').
  \item \textbf{Prospective} --- intentions with an event or time cue (see the Prospective Queue).
\end{itemize}

\section{Write Path (summary)}
Attention gate $\rightarrow$ surprise gate $\rightarrow$ observe and score salience $\rightarrow$
embed and sparse-separate $\rightarrow$ reconcile
\texttt{NEW}/\texttt{SKIP}/\texttt{UPDATE}/\texttt{SUPERSEDE} $\rightarrow$ route tier $\rightarrow$
persist, write links, and emit an event. Full granular flow in \emph{Process Flows: Write Path}.

\section{Recall Path (summary)}
Classify the cue $\rightarrow$ choose the policy $\rightarrow$ seed nodes $\rightarrow$ run the three
legs (semantic $\cup$ lexical $\cup$ associative) $\rightarrow$ spread activation with decay
$\rightarrow$ complete the cluster $\rightarrow$ score confidence (metacognition) $\rightarrow$ curate
the Context Card $\rightarrow$ emit a recall event. Full granular flow in \emph{Process Flows: Cue
Typing, Spreading Activation, and Pattern Completion}.
