\section{Overview}
Tottie is a memory layer that any agent can mount. The \textbf{core engine} owns the memory
lifecycle; the \textbf{MCP server} is the transport that exposes it; the \textbf{Tottie UI} and any
\textbf{IDE coding agent} are consumers that share the same store.

\section{The Four Minds}
Each component has exactly one job. The primary agent (the ``present thought'') is untouched --- it
simply receives better context and can \emph{probe}.

\begin{longtable}{@{}p{0.16\textwidth}p{0.40\textwidth}p{0.30\textwidth}@{}}
\toprule
Mind & Job & Output \\
\midrule
\textbf{Observer} & Runs \emph{in parallel} on every turn; decides ``is this worth remembering?'' & JSON verdict (keep, salience, reason, candidates) \\
\textbf{Scribe} & Structure, tag, embed, \textbf{reconcile}, route to a tier & rows + a \texttt{memory\_event} \\
\textbf{Retriever} & Runs on \emph{every} request; hybrid search across tiers & ranked hits \\
\textbf{Curator} & Assemble the compact \textbf{Context Card} the agent receives & card text + pointers \\
\bottomrule
\end{longtable}

\section{The Tier Model}
\begin{itemize}
  \item \textbf{Identity} --- persona and permanent constraints. Pinned \emph{raw} into the card,
  zero search overhead. (Example: a partner's birthday.)
  \item \textbf{Episodic} --- chronological decisions, state changes, and history.
  \item \textbf{Knowledge} --- ingested documents, files, and references (semantic facts).
  \item \textbf{Procedural (``Lessons'')} --- mistake $\rightarrow$ problem+solution pairs, surfaced
  instantly on recurrence (``autosave'').
\end{itemize}

\section{Write Path (summary)}
Observe $\rightarrow$ embed $\rightarrow$ reconcile $\rightarrow$ route tier $\rightarrow$ persist
and emit an event. The live Memory Panel renders each step. Full granular flow in
\emph{Process Flows: Write Path}.

\section{Recall Path (summary)}
Embed the utterance $\rightarrow$ always include the Identity slice $\rightarrow$ hybrid
(vector $\cup$ full-text) with Reciprocal Rank Fusion $\rightarrow$ procedural slice $\rightarrow$
Curator builds the Context Card $\rightarrow$ emit a recall event. \textbf{Dual-path recall:} the
card is ambient (auto-injected), the probe is deliberate (on demand).
