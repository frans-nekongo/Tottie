\chapter{System Architecture}

\section{Overview}
Tottie is a memory layer any agent can mount. The \textbf{core engine} owns the memory lifecycle; the
\textbf{MCP server} is the transport; the \textbf{Tottie UI} and any \textbf{IDE coding agent} are
consumers that share one store. The engine's behaviour is specified in \emph{The Cognition Model}; its
security in \emph{Security}; its speed in \emph{Performance}.

\section{Runtime Shape}
The engine is \textbf{async throughout}. A single psycopg \texttt{AsyncConnectionPool} is created at startup; the
embedder is loaded once and called from a thread pool. The write path is a \textbf{bounded queue}
drained by a small worker pool, so an Observer model call never blocks a user turn. Recall runs inline
under a hard wall-clock budget. See \emph{Performance} for the budgets and \emph{Security} for the
trust controls that guard what may be written and what may be injected.
