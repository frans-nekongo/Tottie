\section{Gating}
A phase does not begin until the prior phase's \textbf{docs} are written and its tests (where
applicable) pass. If time runs short, cut in this order: STRETCH $\rightarrow$ Completer $\rightarrow$
Consolidator (degrades to a summary stub) $\rightarrow$ Prospective Queue $\rightarrow$ Ranker + Compressor.
\textbf{Never cut the Surprise Gate, the trust/quarantine controls, the eval harness, or the demo video.}
Decided in the v6 audit: the Transactive Directory is cut for the hackathon; the Completer ships
rule-based (cluster grouping, no LLM reconstruction); the cue classifier is rules-only;
retrieval-induced suppression ships behind \texttt{TOTTIE\_RIF\_ENABLED=0} and is measured, not
assumed; imagination / episodic future thinking is explicitly deferred (no demo beat, no rubric
column).

\section{Eval Harness Contract}
\texttt{eval/harness.py} runs every scenario in \texttt{scenarios.jsonl} twice --- memory ON and
memory OFF --- against the pinned brain model (temperature 0, recorded model ids) and reports:
answer accuracy, memory-hit@k, contradiction-correctness, tokens/query, and p50/p95 latency.
Four special checks sit beside the Q/A suite: \textbf{revival} (rank a memory out, then prove the
cue returns it), \textbf{surprise-gating} (chit-chat writes nothing, first real facts always
land), \textbf{consolidation} (Sleep turns N episodic rows into semantic rows without losing the
raw episodes), and \textbf{quarantine} (a low-trust identity write is visible but never injected
until confirmed). Scenario target is 40; the suite ships 20 and grows during P8.
