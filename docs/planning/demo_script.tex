\section{Music and Pacing}
Cinematic and rising under the reveal; a small pulse on the ``spreading activation'' beat; a
\emph{brief quiet} under the constraint scene (let the words land), then a lift on ``memory without the
bug''; a calm passage under Sleep; a beat drop on the ablation flip; a warm settle under the joke.
Cuts land on caption boundaries. Keep on-screen text large; assume a phone screen.

\section{Filming Protocol (known vs unknown scenarios)}
\textbf{Known (scripted):} every scripted take gets a \textbf{shot card} written \emph{before}
rolling --- fixed seed data, fixed turns, and the expected Panel + graph states (which badge,
which nodes, which path lights). Temperature 0, pinned model ids, same seed every take.
\textbf{Unknown (exploratory):} unscripted conversation, verified \emph{post-hoc} against the
session log (did it form memories? does the recap hold? does the story path check out?); run
several, keep the best. \textbf{Every take} logs take number + seed + model ids + verdict in a
run sheet; takes are reviewed the same evening, R-gate style, and only reviewed takes enter the
edit.

\section{Hallway Test (5 minutes, before filming)}
Hand a friend the running UI with zero explanation beyond ``talk to it, watch the right side.''
They think aloud; you only watch and note. Pass criteria: (1) they notice the Panel reacting to
their first message without prompting; (2) they can say in their own words what a
\texttt{NEW} / \texttt{SUPERSEDE} badge meant; (3) they find the 3D brain tab unprompted;
(4) the ablation flip (ON $\rightarrow$ knows, OFF $\rightarrow$ doesn't) surprises them.
Any criterion missed $\rightarrow$ fix the UI or the shot order \emph{before} rolling takes.
