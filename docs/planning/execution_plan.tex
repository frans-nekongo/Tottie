\chapter{Execution Plan: Waves, Gates, and Proof}

\section{Objective and Constraints}
Solo, part-time, Oct 27--Nov 4 ($\approx$ 35~hours). The plan builds \textbf{vertical slices},
not horizontal layers: write $\rightarrow$ recall $\rightarrow$ card first (the thesis, demoable
by day~3), then correctness, visibility, depth, and ship. Three \textbf{revision gates} interrupt
the build to demo the real slice, judge direction, fix errors, calibrate, sync docs, and commit.

\section{Coverage and Estimation Discipline}
\textbf{The Joel Test} (notebook audit: 6/11, five gaps closed here): one-step build
(\texttt{make verify}), CI on every push (\texttt{.github/workflows/ci.yml}: pytest on a pgvector
service + UI build), bug database (GitHub Issues --- the repo stays LaTeX-pure --- plus the
per-gate bug lists), testers (the harness + web3d critique gate), and a 5-minute hallway usability
test in P9 before filming. Bugs-before-features and the schedule were already passes via the
gates and waves.
\textbf{Estimation:} single-point hours sit at the wide end of the Cone of Uncertainty (up to 4x
on the high side), so the 35-hour capacity is split honestly: 27 in waves (W0 3, W1 4, W2 4,
W3 4, W4 5, W5 4, W6 3), 4 in revision gates (R1 1, R2 1.5, R3 1.5), and 4 explicit buffer for
debugging, test maintenance, and filming overruns. Remaining work is re-estimated at each gate
(progressive elaboration). \textbf{Circuit breaker:} if the write/recall/MCP pipe is not working
by hour 25, freeze features and spend the rest on cleanup, tests, and film.

\section{Test Strategy}
A real \texttt{tottie\_test} database (same \texttt{schema.sql}, truncated per test).
Deterministic tests always run: cue rules, surprise/confidence math on fixed vectors, SQL
behaviour on fixtures. LLM-touching tests run against the configured provider and
skip-with-reason when no provider is up --- an honest skip, documented, never a mocked pass.
The retrieval path is never mocked: faking it would test nothing.
