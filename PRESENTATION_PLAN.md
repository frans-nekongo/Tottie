# TOTTIE — Meta Presentation Video Plan

> **Format:** talking-head + screen capture + memes + motion graphics. Target runtime **~11 min**
> (with a 3-min cutdown mapped at the bottom).
> **Story in one sentence:** "I was mad at my agent for forgetting — then I realized it's not
> stupid, it's amnesiac — so I copied the brain and built it a memory."
> **Vibe:** Casey Neistat energy (fast cuts, timelapses, music-driven montages, giant text
> overlays) × Good Work-style clean explainer chapters (kinetic type, b-roll metaphors, numbered
> frameworks) × movie-review-creator directness (talk to camera like a friend, meme inserts,
> pause-and-explain, skits, verdict energy).

## Visual language bible (applies to the whole video)

- **Hook in the first 5 seconds.** No intro card, no "hey guys." Cold-open mid-rage.
- **A cut or visual change every 3–7 seconds.** Jump cuts on every sentence; never hold a static
  frame while talking. B-roll, zoom punch-ins, captions, or memes fill every breath.
- **Giant kinetic captions.** Every key line gets huge on-screen text (Neistat style). Assume phone
  screens — text must be readable at thumbnail size.
- **Chapters.** Each act gets a Good Work-style title card: `ACT 4 — THE BRAIN BABY`. Burn them in
  AND put them in the YouTube description as timestamps.
- **Review-creator direct address.** When a big idea lands, cut to close-up, look dead into the
  lens, and say it slow. Then smash-cut back to pace. That contrast is the retention trick.
- **Meme inserts with SFX.** Air-horn / vine-boom / record-scratch on every meme. Never a silent meme.
- **Music bed.** Cinematic-rising under reveals, lo-fi under explanations, total silence for exactly
  one line per act (the thesis line). Silence is the loudest SFX.
- **Color code the science.** Brain/bio stuff = warm amber. Tottie/system stuff = teal/green.
  Keep this consistent in every diagram — the audience will start reading color before words.
- **Girlfriend counter.** Top-right, always. `💀 girlfriend mentions: N`. Pops with a +1 animation
  and a soft "ding" every time. Final count: **7**. (Recount before locking the edit if you cut a mention.)

## Setup / gear (keep it simple, Neistat rules)

- Talking head: one camera, window light or one softbox, slightly messy desk in frame (lived-in > studio).
- Screen capture: 1080p minimum, cursor highlighted, terminal + UI font sizes bumped up for video.
- Second angle: overhead phone shot of desk/whiteboard for the architecture act.
- Whiteboard or big paper for the live-drawn brain→system map. Real marker > digital for this beat.
